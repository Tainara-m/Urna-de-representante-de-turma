# Sistema de Votação Escolar

Sistema web desenvolvido para a eleição de representantes e vice-representantes de turma da **Escola Estadual Vicente de Paula Fraga**.

## 📌 Descrição

Este projeto simula uma eleição escolar digital, permitindo que os estudantes votem de forma simples, rápida e anônima.

O sistema é totalmente executado no navegador, sem necessidade de servidor ou banco de dados externo.

---

## ⚙️ Funcionalidades

- Seleção de turma (6º ano EFTI ao 3º ano EMTI)
- Listagem dinâmica de candidatos por turma
- Confirmação de voto antes do envio
- Animação visual ao concluir votação
- Armazenamento de votos via `localStorage`
- Painel administrativo protegido por senha
- Exibição de:
  - Representante (1º lugar)
  - Vice-representante (2º lugar)
- Filtro de resultados por nível (EFTI / EMTI / Todos)
- Exportação dos resultados em CSV
- Opção para zerar votos
- Interface totalmente responsiva

---

## 🧠 Tecnologias Utilizadas

- HTML5  
- CSS3  
- JavaScript (Vanilla)  
- LocalStorage  

---

## 🚀 Como Executar

1. Baixe ou clone o projeto
2. Abra o arquivo `index.html` em qualquer navegador moderno
3. Utilize normalmente o sistema de votação

---

## 🗳️ Fluxo da Votação

1. Selecionar turma  
2. Escolher candidato  
3. Confirmar voto  
4. Receber mensagem de confirmação  

---

## 🔐 Painel Administrativo

Para acessar os resultados:

- Clique em **"Painel de resultados"**
- Insira a senha administrativa:

```txt
adm103993
```
## 📊 Recursos do Painel

- Visualização de votos por turma  
- Ranking automático dos candidatos  
- Identificação de representante e vice  
- Filtros por nível de ensino  
- Exportação em CSV  
- Reset completo dos votos  

---

## ⚠️ Limitações Importantes

- Os votos são armazenados apenas no navegador atual  
- Não há sincronização entre dispositivos  
- Limpar o navegador apagará os votos  
- Não há sistema de autenticação de usuários
